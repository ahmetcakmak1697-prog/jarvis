**Yöntem önce kalibre edildi:** 1a'nın altı cevabında bu sayım Ollama'nın

İki bağımsız yol — metnin yeniden sayılması ve bağlantı payı düşülmüş türetme —
aynı sonucu veriyor. ETAP 5'in 60 llama cevabının **tamamı** sayıldı: en uzun

### 1c. Şişmenin kaynağı — `localhost` = 2,05 s

Koşucu Ollama'ya `http://localhost:11434` ile bağlanıyor
(`eval/run_turkish_quality.py` → `_ollama_ask`). Bu makinede ölçüldü:

```
getaddrinfo("localhost") sırası : ['::1', '127.0.0.1']
urllib → localhost  /api/version : 2.032s 2.052s 2.054s   (tekrar: 2.038s 2.053s 2.055s)
urllib → 127.0.0.1  /api/version : 0.015s 0.016s 0.001s
```

Önce IPv6 (`::1`) deneniyor, ~2 s sonra IPv4'e düşülüyor. Koşucunun `total_s`'i
bu bekleyişi içerir; `raw_tps` ise Ollama'nın `eval_duration`'ına bölünür.
Çarpım bu yüzden `eval_count × total_s / eval_duration` olur ve kısa
cevaplarda 4 kata kadar şişer.

DeepSeek yolunda iki sayı aynı saate dayanır ve çarpım sağlayıcının sayacına
**tam** eşittir (sondanın 60 cevabında en büyük fark 0,000 token). §1'in
DeepSeek sütunu bu yüzden doğruydu; yanlış olan yalnız llama sütunu.

**Etkisi:** puanlar etkilenmez (puanlayıcı süre okumaz). Ollama yolunda
`total_s` ve ondan türetilen her şey vaka başına ~2,05 s şişik.
**Düzeltilmedi** — kart ölçer ve yazar. Aynı gecikmenin başka Ollama
istemcilerinde (ör. ses yolu) olup olmadığı **ölçülmedi**.

> ETAP 5 raporunun eki bu çarpımın Ollama'da token vermediğini yazmıştı;
> §1'in llama sütunu yine de o çarpımla hesaplanmış.

### 1d. §1'in sezgisi başka biçimde doğru — aynı metin, iki tokenizer

DeepSeek sondasının 50 token'ı aşan 40 cevabı llama tokenizer'ıyla da sayıldı:

| aynı metin | DeepSeek | llama3.1 |
|---|---|---|
| karakter/token | 2,41 | 3,21 |

`llama_token / deepseek_token` medyan **0,746** (aralık 0,639–0,920). Aynı Türkçe
metin llama'da ~%25 daha az token tutuyor; **400 token llama'ya ~%34 daha uzun
metin izni veriyor** (1 / 0,746).

Yani tavan iki sağlayıcıda da tavandır — ama **aynı tavan değildir.** Bütçe
hiçbir cevabı kesmediği sürece bu asimetri puana girmez; kestiği anda iki model
farklı uzunlukta metinde kesilir.

## 3. ADIM 3 — Önerilen bütçe: **2000** (UYGULANMADI)

**En uzun kendiliğinden duran cevap** (sağlayıcının kendi sayacıyla):

| | 400 bütçeyle (ETAP 5) | 2000 bütçeyle (sonda) |
|---|---|---|
| DeepSeek | 370 | **462** |
| llama3.1 | 345 | **644** |

Üç gerekçe (ETAP 1 şablonu):

1. **Doğrudan gözlendi.** 2000 koşulan sayıdır: DeepSeek'in 60 cevabının 60'ı,
   llama'nın 59'u kendiliğinden durdu; tek istisna §2'deki dejenere sayma
   döngüsü, ve o bütçeyle değil yeniden örneklemeyle durdu. 1000 gibi bir sayı
   644'ün üstünde kalırdı ama **koşulmadı**; ölçülmemiş bir sayıyı seçmek kartın
   yasakladığı tahmindir.
2. **Bütçe bir tavandır, tüketim değil.** Medyan cevap iki bütçede aynı
   (DeepSeek 67→67, llama 21,5→20): tavan normal cevabı biçimlendirmiyor, yalnız
   kesiyor. Kullanılmayan token ne üretilir ne faturalanır. **Bedeli** var ama
   başka yerde: dejenere bir cevap bütçenin tamamını tüketir — llama
   `t1_mix_002` 2000 token, 76 tok/s'de ~26 s (400'de ~5 s). Büyük tavanın
   maliyeti para değil, bozuk cevaplarda **süre**.
3. **Koşu-arası oynaklık payı.** Aynı vaka koşudan koşuya iki katına çıkıyor
   (llama `t1_tr_014` 307→644; DeepSeek `t1_tr_001` 172→462). En uzun gözlemin
   hemen üstüne sıkışmak bir sonraki koşuda yine duvara çarpar; 2000, gözlenen en
   uzun doğal cevabın ~3,1 katı.

Sonuç olarak (gerekçe değil): bütçe hiçbir cevabı kesmediğinde §1d'deki
tokenizer asimetrisi puana girmez. llama'da `num_ctx=4096`: prompt 1023–1079 +
2000 ≤ 3079 — pencereye sığar.

## 5. Yazılan ama düzeltilmeyen bulgular

1. **`localhost` gecikmesi** (§1c) — koşucunun Ollama `total_s`'i vaka başına

```python
"""Sonda: 400 butceli vakalari verilen butceyle kosar ve SAGLAYICININ KENDI
sayacini okur. Istek kurulumu ve yeniden deneme kosucunun kendisidir; yalniz
ag cagrisi sarilir (DeepSeek: _http_json, Ollama: urllib.request.urlopen)."""
import argparse, json, time, urllib.request
import eval.run_turkish_quality as m

ap = argparse.ArgumentParser()
ap.add_argument("--saglayici", choices=["ollama", "deepseek"], required=True)
ap.add_argument("--butce", type=int, required=True)
ap.add_argument("--ids", default="")
ap.add_argument("--out", required=True)
a = ap.parse_args()

vakalar = [c for c in m.load_cases()
           if int(c.get("num_predict") or m.DEFAULT_NUM_PREDICT) == 400]
if a.ids:
    istenen = a.ids.split(",")
    vakalar = [c for c in vakalar if c["id"] in istenen]
    assert len(vakalar) == len(istenen), "bilinmeyen id"

ham = {}
if a.saglayici == "deepseek":
    _orij = m._http_json
    def _sar(url, govde, basliklar, timeout):
        d = _orij(url, govde, basliklar, timeout)
        s = (d.get("choices") or [{}])[0]
        u = d.get("usage") or {}
        ham["son"] = {"completion_tokens": u.get("completion_tokens"),
                      "prompt_tokens": u.get("prompt_tokens"),
                      "finish_reason": s.get("finish_reason")}
        return d
    m._http_json = _sar
    sor, model = m._api_ask, "deepseek/deepseek-chat"
else:
    _orij = urllib.request.urlopen
    def _sar(istek, *x, **y):
        with _orij(istek, *x, **y) as yanit:
            govde = yanit.read()
        d = json.loads(govde.decode("utf-8"))
        ham["son"] = {k: d.get(k) for k in (
            "eval_count", "prompt_eval_count", "done_reason", "eval_duration",
            "prompt_eval_duration", "load_duration", "total_duration")}
        class _Yanit:
            def __enter__(self): return self
            def __exit__(self, *e): return False
            def read(self): return govde
        return _Yanit()
    urllib.request.urlopen = _sar
    sor, model = m._ollama_ask, "llama3.1:latest"

kayitlar = []
for v in vakalar:
    ham.clear()
    seviye = m._CATEGORY_LEVEL.get(v.get("category", ""), "L2")
    zemin = m.build_grounding(v.get("seed_memory"))
    k = {"id": v["id"], "category": v.get("category"), "butce": a.butce}
    try:
        c = sor(model, v["prompt"], seviye, system_extra=zemin, num_predict=a.butce)
        k.update({"text": c.get("text", ""), "done_reason": c.get("done_reason"),
                  "raw_tps": c.get("raw_tps"), "total_s": c.get("total_s"), "error": None})
    except Exception as exc:
        k.update({"text": "", "done_reason": None, "raw_tps": None, "total_s": None,
                  "error": f"{type(exc).__name__}: {exc}"})
    k["sayac"] = dict(ham.get("son") or {})
    k["karakter"] = len(k["text"])
    kayitlar.append(k)

json.dump({"saglayici": a.saglayici, "model": model, "butce": a.butce,
           "kayitlar": kayitlar}, open(a.out, "w", encoding="utf-8"),
          ensure_ascii=False, indent=2)
```

def raw_say(metin):
    govde = {"model": "llama3.1:latest", "prompt": metin, "raw": True, "stream": False,
             "options": {"num_predict": 1, "temperature": 0}}
    istek = urllib.request.Request("http://127.0.0.1:11434/api/generate",
                                   data=json.dumps(govde).encode("utf-8"),
                                   headers={"Content-Type": "application/json"}, method="POST")

        return json.loads(r.read().decode("utf-8")).get("prompt_eval_count")
